Hodgkin–Huxley Simulator

Windows · macOS · Linux

A cross-platform Python desktop application implementing the Hodgkin–Huxley equations to model action-potential generation and single-compartment membrane dynamics in real time.

The application exposes membrane voltage, injected and ionic currents, sodium, potassium, and leak conductances, and the m, h, and n gating variables. Outputs were validated against the NEURON Simulator and documented with methods, error analysis, and biological interpretation.

Hippocampal Network Model

Python · NEURON · Public morphology data

A biophysically grounded network model of the hippocampus built in Python and NEURON.

The project will combine curated neuronal morphologies and public cell-type data to investigate how single-cell membrane properties scale into network behavior. Development currently focuses on data selection, morphology preparation, model architecture, and reproducible simulation workflows.
