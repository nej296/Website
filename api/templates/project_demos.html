Hodgkin-Huxley Neuron Simulator

A Python desktop app for exploring Hodgkin-Huxley membrane dynamics.

The simulator lets users adjust Hodgkin-Huxley parameters and visualize membrane voltage, injected current, and action-potential metrics in the desktop Python app.
