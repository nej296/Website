Hodgkin–Huxley Simulator

Windows · macOS · Linux

A cross-platform Python desktop application for exploring action-potential generation and single-compartment membrane dynamics in real time.

The simulator implements the Hodgkin–Huxley equations and exposes membrane voltage, injected and ionic currents, sodium, potassium, and leak conductances, and the m, h, and n gating variables.

Outputs were validated against the NEURON Simulator and documented in a research-style manuscript covering methods, error analysis, biological interpretation, and future extensions.

Hippocampal Network Model

Python · NEURON

A biophysically grounded network model connecting curated neuronal morphologies to emergent hippocampal network behavior.

The project will integrate public morphology and cell-type data into a reproducible NEURON workflow. Current work focuses on selecting source data, preparing morphologies, defining model architecture, and establishing validation criteria before network experiments begin.
