Hodgkin–Huxley Simulator

A cross-platform Python desktop application for exploring action-potential generation and single-compartment membrane dynamics in real time.

The simulator exposes membrane voltage, injected and ionic currents, conductances, and gating variables. I validated its output against the NEURON Simulator and documented the methods, error analysis, and biological interpretation in a research-style manuscript.

Hippocampal Network Model

A biophysically grounded model connecting curated neuronal morphologies to hippocampal network behavior.

The project uses Python and NEURON to integrate public morphology and cell-type data. Current work focuses on source-data selection, morphology preparation, model architecture, and validation criteria.
