Hodgkin–Huxley Neuron Simulator

Built a biophysical neuron simulator from the ground up using the Hodgkin–Huxley mathematical framework. Investigated how sodium and potassium conductance parameters shape neuronal spike behavior, then validated outputs against NEURON to confirm numerical accuracy and biological realism. Findings were documented in a full research-style paper, treating the project with the same rigor as a published study.
